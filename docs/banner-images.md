# Homepage banner images

Generated with the built-in image generation tool. These are illustrative college marketing images, not photographs of a named campus.

Add the four starter banners with `php artisan db:seed --class=BannerSeeder`. Existing records are preserved. Manage their titles, visibility and order under **Admin → Banners**.

Images fill the hero using `object-fit: cover`; desktop height is capped at 600px, and mobile height starts at 220px. Center important subjects to allow mobile cropping.
